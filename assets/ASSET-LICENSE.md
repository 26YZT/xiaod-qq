# 素材来源与使用范围

代码许可证不自动覆盖声音、图片或视频。

- `voices/C.wav`：来源为尹紫鹭幻想社的 [YinZilu/da-fei-yu-girl-voice-zh](https://www.modelscope.cn/datasets/YinZilu/da-fei-yu-girl-voice-zh)，已通过MiMo克隆合成并保存参考。采用CC BY-NC 4.0，保留署名、来源、修改说明；非商业使用。
- `voices/F.wav`、`G.wav`、`H.wav`、`I.wav`、`L.wav`：维护者以MiMo文字设计生成并保存的参考声线。没有进行训练或对原试听变调。可随本项目用于非商业部署和演示，保留出处；服务接口的使用仍受MiMo条款约束。
- `banner.png` 与 `welcome.png`：使用维护者提供的鲸鱼娘形象作为参考，通过内置imagegen生成；没有使用参考截图中的真人头像。可随本项目用于非商业部署和展示，保留出处；不额外授权第三方角色、商标等权益。
- `media/qq-demo.mp4`、`preview.gif` 与 `demo-poster.jpg`：由维护者提供的真实QQ录屏派生，真人头像列已模糊处理，视频转为H.264/AAC并移除原媒体元数据。用于本项目效果演示，不是所展示歌曲的独立授权音源。

初始视觉是社区鲸鱼娘二创风格，本项目不代表DeepSeek、QQ或相关服务方。涉及第三方形象与歌曲的进一步再分发或商用，应取得对应权利人的许可。
