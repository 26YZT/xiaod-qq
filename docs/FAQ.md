# 常见问题

### 为什么不能只下载仓库就沿用演示里的账号？

公开包包含程序、模板与参考音色。QQ登录、API Key、密码和聊天记忆是每个人自己的，安装后必须填写并扫码。不会开放维护者的账号或额度。

### 需要云服务器吗？

不需要。Mac保持开机、联网，Docker和AstrBot保持运行即可。关闭Docker会断开QQ桥接；关闭AstrBot后不会自动回复。唱歌占用本机计算资源。

### 群里没有回复，是角色卡没接上吗？

先确认群号已配置、托管号已入群、QQ在线，再检查@回复。普通不@消息受语义判断、10秒判断间隔、90秒冷却和每小时上限控制，不是每句都回。

人格在原生「人格设定」中修改；不要同时给多个插件写互相矛盾的人设。项目的群聊和私聊使用同一张初始角色卡。

### 有文字，没有语音？

检查MiMo Key、余额、区域和 `mimo-v2.5-tts-voiceclone` 权限；确认默认音色为L。网络或合成失败会回退文字。群聊必须明确要求语音，普通聊天不自动每次发语音。

### 语音或点歌工具没有调用？

聊天模型配置必须保留 `tool_use`。只设 `text` 会被AstrBot过滤工具，即使插件显示“已打开”也无法联动。

### 首次唱歌为什么很慢？

需要找音源、分离伴奏并做本地歌声转换。完整长音源可能等待十几到几十分钟，M4也不等于即时生成。先试一小段，完成后同曲同模式可用缓存。

### 能唱任意歌、任意版本吗？

不能保证。搜索结果不等于可下载的音频。版本、时长和访问限制会影响是否可用；获取失败会提示，不会只用歌词猜旋律。

### 可以商业使用吗？

请分别看代码、声音、图像、数据集、模型与服务条款。代码的AGPL许可不自动授予素材或歌曲商业使用权。C参考音色与本地参考干声采用CC BY-NC 4.0；其他内容见来源说明。

### 怎样更新而不丢记忆？

先停止本套安装，备份 `.local/` 与 `runtime/` 的私人数据，再更新仓库。再次安装会重置运行目录中的插件代码，但首次配置不会重置已存在的角色卡和记忆。升级第三方插件后需要重新验证发送与工具行为。
