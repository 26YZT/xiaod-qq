# 功能配置

## 人格与世界书

初始角色为 `可爱鲸鱼娘小D`。首次初始化会导入 `presets/persona.json`；后续请通过 AstrBot「人格设定」修改原文与预设对话。不会通过覆盖聊天历史来强行切换人格。

世界书位于插件「世界书插件」，8条初始补充围绕海玻璃、饭团、雨天、解谜、收纳、取名与轻微嘴硬等话题。目标群的小约定会绑定初始化时填写的群。它们是角色想象，不代表真实发生的共同经历。

## 群聊参与

只对配置的目标群开放。机器人被@、被点名、被引用时使用原生唤醒；不@时综合当前角色、说话对象和最近话题判断。

公共问题、话题延续、角色玩笑和庆祝有机会参与；零散的会员额度抱怨、指代不明、群友互相交代事情和已经结束的话题保持克制。出现某个词并非固定触发。

默认90秒主动冷却、每小时最多8次、判断间隔10秒。连续消息会稍后判断最后一条，过时回答会丢弃。冷却期间的普通不@消息仍可能不回复。

调整入口：插件 → 小D群聊节奏。记忆只保存自己允许的群，摘要使用配置的聊天模型，因此会有模型调用。

## 私聊主动消息

初始只联系主人号，2～4小时低频，23:00～09:00安静，无回复不连续追发。`init` 会询问是否允许，也可在主动消息插件配置中关闭。

它使用本机运行后的对话，不包含维护者的共同经历。不要同时在其他新装插件里再开启一套相同的主动机制。

## MiMo和L音色

MiMo插件与小D语音节奏配合使用：默认声线固定L，自动情绪路由与语音导演关闭，降低声线漂移。

- 私聊明确要求语音时合成；关键时刻允许低频语音。
- 群聊仅明确要求语音时合成。
- 语音合成使用同一份已生成正文；失败时回退同正文文字。
- MiMo自身的普通自动TTS保持关闭，由小D语音节奏控制发送，避免重复。

语音库附C/F/G/H/I收藏供选择。日常说话默认改成其他音色后，唱歌模块会拒绝静默切换为另一声线；本发布版的唱歌预设专门固定为L。

## 自动点歌

完整唱歌环境安装且完成模型校验后启用。默认完整音源；“一小段/试听”选人声集中的12秒；每段QQ语音≤45秒。

在线获取使用已验证的YouTube渠道，不读取浏览器Cookie。只处理实际可获取、时长≤6分钟的音源；网络和站点规则变化可能造成失败。

伴奏从同一条录音分离，并与升3个半音的L人声同步调性，避免拼接不同版本导致错拍。制作任务串行运行，完成后缓存；可查进度和取消，重启不重播未完成任务。

本地清唱歌库的5条参考干声来自署名数据集，长度是数据集现有轨道的长度，不是对“官方整首”的承诺。首次安装会校验这些参考文件，遵守CC BY-NC 4.0。

## 表情包

默认附一张新生成的小D欢迎表情。通过「表情包管理器」继续导入自己有权使用的图片包。仅贴切时发送，一次最多一张；不适合时用文字。

默认不自动收集群友图片，不开启云端同步，不需要为基线效果另配嵌入或重排序模型。额外启用语义向量索引时，再按对应插件要求配置。

## QQ动态与签名（默认关闭）

插件「小D动态与签名」提供草稿和受限调度。私聊主人可用“小D日常预览”查看草稿，不会发布。

在明确希望自动公开表达、确认桥接支持后再开启：默认每周二/四/六一条好友可见动态，个性签名每天最多一次。开启签名前必须在手机QQ关闭“签名同步到空间”，再启用 `signature_sync_off_confirmed`。功能仍受QQ账号与平台限制。

不要在复制本项目后立即为其他人的账号启用对外发布。这里的初始配置保持关闭，未附带任何维护者的发布状态、原签名或QQ空间凭据。
